# Обновление выгрузок

GitHub Desktop не требуется. Текущая инструкция и правила расчёта находятся в [README.md](README.md).

- Для работы в своём браузере используйте **Загрузить выгрузку** на сайте.
- Для общего доступа добавьте файл в `data/raw/` через сайт GitHub и его имя в `data/exports.json`.
- Начальная точка — `tasks_2026-09-16_09-52-52.xls`. Сохраняйте её и последующие выгрузки.
- Пример имени следующего файла: `tasks_2026-09-17_09-30-00.xls`. Указывайте реальную дату и время экспорта.

Если используете GitHub Desktop: синхронизируйте репозиторий, добавьте файл и обновите список, затем **Commit to main → Push origin**. Не заменяйте актуальный проект старыми архивами.
