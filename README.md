# Координация

Статический интерфейс для просмотра и сравнения HTML-выгрузок задач. Работает на GitHub Pages без сервера приложений и сборки.

## Обновление от 17 сентября 2026

- Начало наблюдения: **16.09.2026 09:52:52**.
- Более ранние выгрузки не участвуют в сравнении и удаляются из локального кеша.
- Последующие локальные выгрузки сохраняются.
- Начальный срез не создаёт фиктивных событий и дельт.
- Длительности рассчитываются по наблюдениям в доступных срезах, а исходные даты сохраняются.
- На первом экране видны выбранный период, рабочая очередь и быстрые фильтры. Дополнительная сводка свёрнута.

## Файлы

- `index.html` — структура интерфейса.
- `assets/app.js` — загрузка, обработка, сравнение, отображение и экспорт.
- `assets/style.css` — оформление.
- `data/exports.json` — список общих выгрузок.
- `data/raw/` — исходные файлы.
- `tests/baseline.test.cjs` — проверки базовой точки и истории.

## Добавление выгрузки

Кнопка **Загрузить выгрузку** обрабатывает файл в браузере. Такая загрузка не записывает файл в репозиторий. Имя должно содержать дату и время в формате `tasks_YYYY-MM-DD_HH-MM-SS.xls`. Внутри ожидается HTML-таблица со столбцами названия и статуса задачи.

Для общего доступа добавьте файл в `data/raw/` через GitHub **Add file → Upload files**, затем добавьте его точное имя в массив `files` файла `data/exports.json`. После публикации нажмите **Обновить** на сайте.

Храните срезы начиная с базовой даты для непрерывного сравнения. При нехватке места в локальном хранилище новый файл остаётся только в текущей сессии, о чём интерфейс сообщает явно.

## Проверки

```sh
node --check assets/app.js
node tests/baseline.test.cjs
```

Тесты проверяют начальную точку, накопление наблюдаемой длительности, переходы статусов, очистку старого кеша с сохранением новых файлов, пустой предыдущий срез и границу временной шкалы.
