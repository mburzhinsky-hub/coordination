Перенос и резервная копия базы

Эта страница переносит snapshots, «Кто где», настройки и сохранённые исходные выгрузки между локальным браузером и общим сервером.

1. Экспорт

Скачайте JSON-копию текущей базы. Файл храните как резервную копию.

2. Импорт на общий сервер

Откройте эту же страницу через локальный общий адрес, выберите ранее скачанный JSON и импортируйте его. Импорт доступен только когда страница работает через shared server.
